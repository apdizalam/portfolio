# Abdisalam Mohamed Muhumed — Portfolio

Personal portfolio of a Full-Stack Software Engineer & AI Enthusiast based in Borama, Somaliland.

Plain HTML, CSS and JavaScript — no build step. Open `index.html` in a browser, or serve the folder with any static server.

- `index.html` – page content
- `styles.css` – layout (single centered 720px container, responsive)
- `script.js` – GitHub activity grid, scroll reveal, active nav
- `github-data.js` – snapshot of GitHub contributions
- `assets/` – profile photo and project screenshots
